⚙ Pengaturan Gemini API
Cara mendapatkan API Key Gemini (gratis):
  1. Buka aistudio.google.com/apikey dan login dengan akun Google.
  2. Klik Create API key (Buat kunci API).
  3. Salin kunci yang muncul.
  4. Tempel di kolom di bawah, lalu klik Simpan & Test Koneksi.
Jangan bagikan API key Anda ke orang lain.
